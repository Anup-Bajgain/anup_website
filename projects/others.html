Agricultural UAV Design

A UAV airframe modeled and aerodynamically validated for agricultural monitoring, using Plane Maker and the X-Plane flight simulator.

Approach

  • Modeled the aircraft geometry in Plane Maker
  • Performed aerodynamic validation using the X-Plane flight simulator
  • Extracted and analyzed simulated flight data to verify aerodynamic performance metrics against analytical estimates
