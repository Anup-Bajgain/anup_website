# Nimbus APD assets

The aircraft render, XFLR5 mesh, and plotted results in this directory come from the team project account at [Toran Niroula’s Nimbus page](https://toranniroula.com.np/work/nimbus-agricultural-uav/). They are used here with attribution for Anup Bajgain’s portfolio page for the same team project. The design poster in `projects/reports/nimbus-poster.pdf` comes from the same source. The airframe is a conceptual design and the plots are from digital analysis and simulation; the render is not a photograph of a built aircraft.

The APD page uses original copy and layout. Numerical targets and simulation results are labeled separately. The existing `APD_isometric.PNG` image in the parent directory was already part of this portfolio.
