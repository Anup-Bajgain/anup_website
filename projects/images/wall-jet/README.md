# Final-year project media

Selected experimental photographs and plots in this directory come from the team's [compressible wall-jet / rainbow schlieren project account](https://toranniroula.com.np/work/compressible-wall-jet-rsd/). They are used with attribution on Anup Bajgain's page for the same four-person final-year project. The thesis report at `projects/reports/final-year-project.pdf` comes from that account. Page copy and layout are original to this portfolio.

The page distinguishes measured RSD results, CFD estimates, and qualitative image comparisons. In particular, the reported nozzle exit Mach numbers are CFD estimates, not direct velocity measurements.

Calibration details are also based on the team's [pyrsd library account](https://toranniroula.com.np/work/pyrsd-library/). The CFD–RSD peak-gradient gap is described as unresolved because limited image resolution and optical averaging, as well as CFD modeling choices, may contribute.
