# Skill tool artwork

Assets are served locally. SVG paths are retained from the sources below; monochrome marks use brand colors. PNG assets retain their original artwork. Brand names and marks belong to their respective owners; their use here identifies portfolio skills.

| Asset | Source |
| --- | --- |
| `python.svg`, `c.svg` | [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons) (MIT); original SVG variants |
| `ansys.svg`, `dassaultsystemes.svg`, `latex.svg` | [Simple Icons v13](https://www.jsdelivr.com/package/npm/simple-icons?version=13) (CC0 icon collection; brand rights remain with owners) |
| `office.svg` | [Simple Icons v9](https://www.jsdelivr.com/package/npm/simple-icons?version=9), Microsoft Office mark |
| `openfoam.png` | [OpenFOAM Foundation](https://openfoam.org/), [foundation site icon](https://cdn.openfoam.org/wp-content/uploads/2016/05/CFDfoundationLogoDark-600x600-150x150.png) |
| `xplane.png` | [X-Plane Developer](https://developer.x-plane.com/), [96px site icon](https://developer.x-plane.com/wp-content/themes/xplane/favicons/favicon-96x96.png) |
| `xflr5.png` | [XFLR5 source mirror](https://github.com/subprotocol/xflr5/blob/master/xflr5-6.10/win/xflr5.ico); ICO converted to PNG |
| `openvsp.png` | [OpenVSP official repository](https://github.com/OpenVSP/OpenVSP/blob/master/vspIcon.png); original PNG icon |
| `xfoil.svg` | Custom airfoil illustration for this portfolio; not an official Xfoil logo |

SolidWorks and CATIA use the shared Dassault Systèmes vendor mark. ANSYS Fluent uses the ANSYS vendor mark. Category icons remain separate from product logos; ML Basics has no named software to brand.
